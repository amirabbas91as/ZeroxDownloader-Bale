# 📥 ZeroxDownloader برای بله (Bale)

بات دانلودر بله — یوتیوب / اسپاتیفای / تیک‌تاک داخل پیام‌رسان بله.

## دیپلوی روی Railway

**ریپو را وصل کن، Railway خودش Dockerfile را می‌سازد:**
- Tor و ffmpeg داخل کانتینر نصب می‌شوند
- `start.sh` اول Tor را بالا می‌آورد، بعد بات را اجرا می‌کند
- متغیر محیطی فقط یکی: `BOT_TOKEN`

```
BOT_TOKEN=توکن بات بله از @BotFather
```

## اجرا محلی (بدون Docker)

```bash
apt install tor ffmpeg        # Tor برای دور زدن بلاک یوتیوب
pip install -r requirements.txt
export BOT_TOKEN="توکن از BotFather بله"
python3 bot.py
```

## دستورات

| دستور | کار |
|-------|-----|
| `/start` | راهنما |
| `/song` | لینک بعدی → MP3 |
| `/video` | لینک بعدی → ویدیو |
| `/videobox 480` | کیفیت یوتیوب |

## نکته یوتیوب

یوتیوب IP دیتاسنترها (Railway، AWS و...) را بلاک می‌کند. بات به‌طور خودکار:
- اگر Tor در دسترس باشد → تمام ترافیک یوتیوب از Tor رد می‌شود
- اگر مداری بلاک شد → تا ۴ بار مدار جدید می‌سازد (NEWNYM)
- اگر Tor نباشد → مستقیم امتحان می‌کند (بعضی مواقع کار می‌کند)

تیک‌تاک همیشه مستقیم و بدون مشکل کار می‌کند.
